# Contributing

If you would like to contribute code to this project, you can do so by forking the repository and
sending a pull request.

When submitting code, please make every effort to follow existing conventions and style in order to
keep the code as readable as possible.

See [README.md](README.md) for local setup and [docs/architecture.md](docs/architecture.md) for module
boundaries and native Remix component conventions. Run `pnpm validate` before submitting a change;
browser installation and test conventions are in [docs/testing.md](docs/testing.md).

Thank you.
